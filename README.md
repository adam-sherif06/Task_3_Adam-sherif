# SQL Data Analysis Project

## Overview

This project was completed as part of the DecodeLabs Data Analytics Internship.

The objective of this project is to analyze a sales dataset using SQL queries and extract meaningful business insights through data filtering, sorting, grouping, and aggregation.

## Skills Used

* SELECT
* WHERE
* ORDER BY
* GROUP BY
* COUNT
* SUM
* AVG

## Analysis Performed

* Total number of orders
* Revenue analysis
* Average order value
* Order status analysis
* Payment method analysis
* Product performance analysis
* Referral source analysis
* Top orders analysis
